Как считаются показатели

Здесь показаны выкупленные товары, отражённые в финансовых отчётах, а не все оформленные заказы. Даты — по операции в финансовом отчёте. Сумма выкупов — цена продавца с согласованной скидкой, включая скидку по промокоду, умноженная на количество товаров. Это не сумма к перечислению и не чистая прибыль.

Возвраты показаны отдельно. Итог — сумма выкупов за вычетом суммы возвратов выбранного периода. Сегодняшние операции появятся, когда Wildberries включит их в отчёт.

Учитываются только ID из сохранённого списка промокодов. Названия и коды сохранены из кабинета WB; новые ID добавляет владелец. Одинаковые названия у разных ID не объединяются. Если отчёт за период загружен полностью, отсутствие операций по выбранному ID показано нулём.

Промокоды в статистике

В статистику входят только ID из этого списка. Для нового промокода укажите ID из карточки WB и название. Нажмите название в таблице, чтобы изменить его.

Доступ только к промокодам

Остальные показатели магазина этому пользователю недоступны. Приглашение активируется после его входа через Telegram.
