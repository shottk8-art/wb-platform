# Аудит производительности — 11 октября 2026

## Основная причина

API сохранял каждую финансовую операцию WB в промежуточную JSON-таблицу.
1 370 459 операций занимали 1 629 233 152 байта. Вся база занимала
1 645 014 163 байта и перешла в режим только чтения. Большой SQL-пересчёт
также исчерпывал место для временных файлов; повторять его было небезопасно.

Операции выгружены в отдельный зашифрованный архив. Проверены SHA-256,
аутентифицированная расшифровка, последовательность ID, все курсоры/счётчики,
денежные суммы 25 загрузок и совпадение всех 14 ранее готовых моделей.
Новые компактные модели сопоставлены с базой: 25 моделей, 0 расхождений.
После этого очищена только промежуточная таблица операций, без CASCADE.
Размер базы после фиксации очистки: **15 813 779 байт**, около **15,8 МБ**.
Сохранены 178 файловых отчётов, 628 строк продаж, 103 записи себестоимости,
82 записи журнала. Архив находится вне репозитория и не публикуется.

## Исправления

- Финансовая страница сохраняет суммы и итоги по уникальным артикулам,
  а не 50 000 исходных строк. Целочисленные копейки и прежние формулы сохранены.
- Суммы, модель и курсор фиксируются одной транзакцией с проверкой предыдущего
  курсора и счётчика. Повторный/устаревший обработчик не удваивает данные.
- Для нового формата запись исходных операций запрещена триггером.
- Две последние пригодные версии месяца сохраняются; предыдущие компактные
  версии удаляются только после готовности замены. Исторические месяцы,
  незавершённые/ошибочные загрузки и ручные данные не очищаются.
- Служебные журналы двух WB cron-задач очищаются после семи дней.
- API-динамика читает последние 12 месяцев: четыре запроса для малого каталога,
  без исходных операций, полных служебных summary и обращения к WB.
- Изменение только счётчика загрузки не перезапрашивает весь дашборд.
  Скрытая вкладка по-прежнему приостанавливает опрос.
- Файловый график получает месячные итоги одним RLS-запросом вместо всей
  истории продаж по товарам. Живая себестоимость и налог не кэшируются.
- Продажи, себестоимость и журнал читаются постранично: каталог из 1105
  товаров больше не обрезается до стандартного лимита 1000 строк.
- Библиотеки XLSX/ZIP загружаются при импорте, а не при открытии обзора.
- auth.uid() в RLS вычисляется один раз на запрос; логика доступа не расширена.

## Проверки

Пройдены регрессии WB API, финансов, рекламных расходов, годовой истории,
повторных запросов, переключения магазинов, мобильного рендера, ленивого
импорта и больших каталогов. Дополнительно выполнены rollback-only SQL-тесты:

- `tests/wb-api-compact-ingestion.sql`: транзакция, повтор, неверные суммы,
  запрет исходных строк, закрытые права RPC.
- `tests/wb-api-read-model.sql`: точное совпадение агрегатов.
- `tests/wb-api-production.sql`: два владельца, изоляция очередей и одноразовых
  аренд обработчика, запрет доступа клиента к ключам/служебным RPC.
- `tests/file-trend-budget.sql`: живая себестоимость, владелец, посторонний,
  анонимный доступ, публичная витрина и отделение Ozon.
- `tests/wb-api-retention.sql`: две версии месяца, готовая замена,
  сохранение исторических/ошибочных загрузок, закрытая очистка.

Предупреждения Supabase о [построчном auth.uid()](https://supabase.com/docs/guides/database/database-linter?lint=0003_auth_rls_initplan)
устранены. [Несколько разрешающих политик](https://supabase.com/docs/guides/database/database-linter?lint=0006_multiple_permissive_policies)
оставлены для владельцев, участников и публичных витрин. Три
[пока не использованных индекса](https://supabase.com/docs/guides/database/database-linter?lint=0005_unused_index)
не удалены только на основании короткой статистики использования.

## Ограничения и дальнейший контроль

Это проверка текущего проекта и регрессий, а не нагрузочный тест с сотнями
одновременных пользователей. После роста аудитории измерять p95 запросов,
размер агрегатов/каталогов, CPU/IO, количество cron-вызовов и egress.
Free-тариф не гарантирует неограниченный масштаб. Показатели и письма Supabase
могут обновляться не сразу: [правила размера базы и квот](https://supabase.com/docs/guides/platform/database-size).
